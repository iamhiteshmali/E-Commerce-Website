# 🛒 E-Commerce Website

A full-stack e-commerce web application developed for online shopping, product management, cart, checkout, orders, and user account management.

## 🌐 Live Demo

🔗 [Visit Live Website](http://ecommerce.hiteshmali.in)

## 📌 About The Project

This E-Commerce Website is designed to provide a complete online shopping experience.

Users can browse products, search and filter products, add products to the shopping cart, manage their account, place orders, and view order information.

The project also includes an Admin Panel for managing products, categories, orders, and other website data.
